# Trang web giới thiệu sách – Lập trình Web từ con số 0

Trang web tĩnh giới thiệu sách, làm bằng HTML, CSS và Bootstrap 5, responsive trên điện thoại, máy tính bảng và máy tính để bàn.

## Các phần của trang
- Header (thanh điều hướng) và Book Overview
- Author
- Features
- Prices
- Download
- Reader's Say
- Footer

## Cấu trúc thư mục
```
book-landing/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## Chạy trang
Mở file `index.html` bằng trình duyệt. Cần có kết nối mạng để tải Bootstrap, Bootstrap Icons và Google Fonts từ CDN.
