HTML và CSS căn bản

Bootstrap 5

Dùng hệ thống lưới, thanh điều hướng, thẻ và biểu mẫu để dựng giao diện nhanh.

Responsive

Làm trang web hiển thị đẹp trên điện thoại, máy tính bảng và máy tính để bàn.

12 dự án thực hành

Mỗi chương kết thúc bằng một sản phẩm nhỏ, như trang cá nhân, landing page, trang tin tức.

Git và GitHub
