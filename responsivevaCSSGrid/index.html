CSS Grid là gì?

CSS Grid là hệ thống bố cục hai chiều, cho phép sắp xếp phần tử theo cả hàng và cột. Nhờ grid-template-areas, bạn có thể đặt tên cho từng vùng và thay đổi vị trí chỉ bằng vài dòng CSS.

Responsive với Media Queries

Bằng cách dùng @media, bố cục có thể đổi từ nhiều cột trên máy tính sang một cột trên điện thoại mà không cần sửa HTML.

Mẹo thực hành

Hãy mở DevTools của trình duyệt, kéo thay đổi chiều rộng cửa sổ và quan sát bố cục thay đổi tại mốc 768px.
